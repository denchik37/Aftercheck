Verify the package offline

With Node.js 24+ and the Aftercheck checkout prepared, extract the package and run from the checkout using the extracted file paths:

npm run cli -- verify evidence.json policy.json output/replay

Compare the generated report.json and report.md with the package. Exit codes: PASS 0 · VIOLATION 2 · UNKNOWN 3 · invalid input 1. Replay needs no RPC connection.
